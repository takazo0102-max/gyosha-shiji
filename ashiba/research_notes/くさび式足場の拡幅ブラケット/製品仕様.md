## 1. 日建リース ND システム（ND1800 / ND1900 / ストロング）の拡幅・張出ブラケット

### Takeaway
ND1800 の拡幅ブラケット NDBK03H は 305 幅で、方杖の下端は腕木から 450 下（1 コマ下）。張出ブラケット NDBK06H は 610 幅で方杖の下端は 900 下（2 コマ下）。強力型（03HS / 06HS）と ND1900 用（NHBK03H / 06H）は先端ソケットから長い方杖を下ろし、下端は 1350 下（ND1800、450×3）または 1425 下（ND1900、475×3）。先端にはホゾ φ36.4（ND 支柱専用）があり、拡幅部の支柱の許容支持力は ND1800 で 8.8 kN/柱（NDBK03H）または 10.0 kN/柱（03HS）、ND1900 は 9.0 kN、ストロングは 13.7〜17.4 kN。

### Inferences
- ND1800 のコマのピッチは 450、ND1900 は 475（既存ノート「支柱の割り付け」）。この値から、方杖の付く位置を次のように読める:
  - NDBK03H: 1 コマ下（450）
  - NDBK06H: 2 コマ下（900）
  - NDBK03HS / 06HS: 3 コマ下（1350）
  - NHBK03H / 06H: 3 コマ下（1425 = 475×3）
- NDBK03H は方杖が短い（450）。そのため拡幅で使うときは、カタログが先端から下層支柱まで補強単管（S2C 留め）を求めている。03HS は長い方杖を持つので、補強単管なしで 10.0 kN になっている（03HS の図に補強単管は描かれていない）。
- 先端の「ホゾ φ36.4」は、上に立てる ND 支柱の下端を受けるホゾ（ND 支柱のホゾ径と同じ φ36.4）。ND の図で先端に立つ支柱は NDP09N（900）。上の支柱と継ぐと、NDP09N の 900 は一層 1800 の半分にあたる。
- 依頼文の「Vol.10 p014、p025」は上記の印刷ページと一致する。

### Gaps
- NDBK03H / 06H の先端ホゾのホゾ長（受けパイプから上に出る長さ）は、p014 の図に寸法がない。
- ND1900 の拡幅・縮幅例の図（ND1800 の p014 のような組立図）は p037 には見当たらない。
- 依頼にある「8.8kN/柱」は確認できた。ただし張出ブラケット NDBK06H を拡幅（上層の幅を広げる）に使えるかどうかの明記は見つからなかった。拡幅部の許容値に名前が出るのは 03H / 03HS だけ。

## 2. 497 幅（方杖 1425・1390）と 305 幅（1425・1357）のカタログはどこのものか

タカミヤの次世代足場「Iq システム」の **Iq 拡幅狭幅ブラケット IQBHK497 / IQBHK305** と、組で使う **Iq 拡幅狭幅アタッチメント**のページと確定した。アタッチメントはレンタル品が IQBHKB / IQBHKA、販売品が IQBHKA497 / IQBHKA305。図の 1425 は、腕木からアタッチメント下端の付くコマまでの**縦の距離**（475×3）。1390 / 1357 は**アタッチメント（斜めに入る方杖材）の部材長**で、ブラケット先端に立てる支柱の長さではない。

### Inferences
- 497 という幅は、Iq の梁間 610 と 1107 の差（1107−610＝497）そのもの。305 は 914−610、1219−914 の差。どちらも「下層の幅＋ブラケット幅＝上層の幅」になるように決めた寸法と読める。
- アタッチメントの部材長は幾何で確かめられる。先端ソケットの下端（腕木から 150 下）から 1425 下のコマまでの縦は約 1275。横はほぼブラケット幅なので、斜めの長さは次のとおり（推定）:
  - 497: √(497²＋1275²)≒1368
  - 305: √(305²＋1275²)≒1311

  端の金具の分を足すとカタログの 1390 / 1357 に近い。この点からも、1390 / 1357 は立てる支柱ではなく斜めの方杖材と判断した。
- ブラケット先端に立つのは、Iq の通常の支柱（上層の支柱）。腕木の上に出る 125 がホゾに相当する。依頼文の「ブラケット支柱 1390 / 1357」はアタッチメント（方杖）を指していると考えられる。
- 方杖の下端の付く位置は、腕木から 3 コマ下（1425）。ブラケット本体の短い斜材は 204 下で支柱に当たる。204 はコマ（475）の位置ではないので、当て板のような受けと推定。
- 8.0 kN / 7.5 kN の値は 497 の図の下にだけある。305 にも同じ値が当てはまるかは書き方から判断できない。
- 610→1107（下層が上層の 55%）は、仮設工業会の技術基準の一般規定「下層の建地間隔が上層の 60％以上」を下回る。技術基準③の「専用部材を使用する場合は、専用部材の組立て、使用基準による」によって認められている扱いと読める（推定）。

### Gaps
- 8.0 / 7.5 kN が IQBHK305 の組立にも当てはまるのかは明記がない。
- アタッチメントの下端の金具がくさびなのかクランプなのかは、図と写真からははっきりしない。図では支柱のコマの位置に付いている。
- ブラケット単体の許容支持力（日建の 6.0 kN に相当する値）は、RIQ p22 の性能表に拡幅狭幅ブラケットの行がなく、確認できなかった。
- アルインコ、ダイサン、平和技研、日綜産業、中央ビルト、ヤグミの拡幅ブラケットは、公開 PDF を検索で見つけられなかった。497 幅の製品はタカミヤ以外に確認できていない。

## 3. 「拡幅時」と「狭幅時」の意味

### Takeaway
拡幅・狭幅はブラケットの向きの呼び名ではなく、**下層から上層へ足場の幅（梁間）が広がるか狭まるか**を表す。拡幅は上層が広い（ブラケットが下層の外へ張り出し、先端に上層の外側の支柱が立つ）。狭幅（日建は「縮幅」）は上層が狭い（ブラケットが下層の支柱間の内側へ向き、先端に上層の新しい支柱が立つ）。

### Cited Findings
- 仮設工業会の技術基準は拡幅を次のように定める:
  - 拡幅とは「下層から上層に向けて幅を広げることをいう」
  - 「① 拡幅は下層の建地間隔が上層の建地間隔の 60％以上であることとし、かつ、全層間で 1 回までとする」
  - 「② 緊結部付ブラケットを使用して拡幅を行う場合は、張出した部分に方杖を設置し、方杖下端の取付け箇所は、緊結部付支柱の腕木材を設けた位置とする」
  - 「③ 足場の拡幅に専用部材を使用する場合は、専用部材の組立て、使用基準による」
  - 「④ 拡幅した層の上部及び下部の前踏み側の全スパンに壁つなぎを設置する」

  — [仮設工業会 技術基準（改訂版）](http://humantecg.co.jp/scaffold/technical%20criteria2015.pdf)
- タカミヤの用語: 「610→1107への拡幅」と「1107→610への狭幅」。許容値の見出しは「拡幅部を含む上層部」と「狭幅部を含む上層部」。図の並びは【拡幅時】が「610｜497」、【狭幅時】が「497｜610」 — [タカミヤ RIQ p11](https://www.takamiya.co/iq/pdf/RIQ.pdf)
- 日建は「拡幅・縮幅例」として 914→1219 と 1219→914 の 2 図を載せる。縮幅の図では、ブラケットが下層 1219 の片側の支柱から足場の内側へ向いている — [日建 Vol.10 p014・p015](https://www.nrg.co.jp/nikkenlease/catalog_data/8192/original.pdf)

### Inferences
- 【拡幅時】の 610｜497: 下層 610 の外側の支柱にブラケットを付け、さらに 497 外へ張り出す。上層は 1107。【狭幅時】の 497｜610: 下層 1107 の片側の支柱からブラケットを内側へ 497 出し、先端に上層の支柱を立てる。上層は 610 で、下層の反対側の支柱とつながる。
- 壁がどちら側にあるかでブラケットの向きが「外向き」「建物向き」になるが、カタログの区別の軸は幅の増減。日建の 2 図はどちらも壁が右側にある。拡幅ではブラケットが壁と反対側（外側）へ張り出し、縮幅ではブラケットが足場の内側（壁側）へ向く。
- 「狭幅」の許容値（7.5 kN）が拡幅（8.0 kN）より低い理由はカタログに書かれていない。上層の支柱が下層の布の途中（支柱のない位置）に載るためと推定する。

### Gaps
- 狭幅の規定は仮設工業会の技術基準（抜粋した範囲）にはなく、メーカーごとの使用基準に任されているように見える。条文としては確認できていない。

## 4. 497 / 305 / 610 のブラケットに載る布板（240 / 500、ハーフアンチ）と枚数

### Takeaway
メーカーの記載からはっきり言えることは 2 つだけ。
- 信和は張出ブラケットの幅を踏板の幅で呼んでいる（600 は「500,400mm幅踏板用」、400 は「250mm幅踏板用」）。つまり 1 枚用の設計。
- タカミヤの 305（拡幅狭幅）には「杉足場板のみ、ハーフアンチ不可」とある。

拡幅・狭幅ブラケットの本来の役目は、先端に上層の支柱を立てて足場の幅を変えること。上層の床は通常の布材と布板で組む。

### Cited Findings
- 信和 キャッチャー: SBH-40 は「600mm(500,400mm幅踏板用)」、SBH-25 は「400mm(250mm幅踏板用)」。ブラケット SB-40・SB-25 も同じ書き方 — [信和 ver311 p27](https://www.shinwa-jp.com/download/pdf/ver311.pdf)
- タカミヤ Iq 拡幅狭幅ブラケット（IQBHK305 の図の下）: 「使用いただけるのは杉足場板のみです。（ハーフアンチはご使用いただけません）※くさびやフランジがあり、アンチの爪が入らないため」 — [タカミヤ RIQ p11](https://www.takamiya.co/iq/pdf/RIQ.pdf)
- Iq の布板（Sウォーク）は巾 490 と巾 240。長さは 1829・1524・1219・914・610。許容荷重は巾 490 が 2,450 N、巾 240 が 1,176 N — [タカミヤ RIQ p11 下段](https://www.takamiya.co/iq/pdf/RIQ.pdf)
- 日建 ND の布板は幅 500（実幅 490）と幅 240（既存ノート「支柱の割り付け」が日建 Vol.10 p005–007 から引用） — [日建 Vol.10](https://www.nrg.co.jp/nikkenlease/catalog_data/8192/original.pdf)
- 日建の拡幅例（914→1219）: 上層では、下層の内側の支柱が中間支柱として上へ伸び、先端の支柱との間を「つなぎ材 NDT03」（305）でつなぐ — [日建 Vol.10 p014 図](https://www.nrg.co.jp/nikkenlease/catalog_data/8192/original.pdf)
- 日建 NDBK03H の芯々 305 は、内法 241＋両端（20.5 / 42.7）。NDBK06H の 610 は内法 546＋両端 — [日建 Vol.10 p014](https://www.nrg.co.jp/nikkenlease/catalog_data/8192/original.pdf)
- Iq 張出ブラケット 610 / 360 の腕木の内法は 560 / 310 — [タカミヤ RIQ p10](https://www.takamiya.co/iq/pdf/RIQ.pdf)

### Inferences
- 305 幅（日建 NDBK03H / 03HS / NHBK03H、Iq IQBHK305、JFE JHBK-3）: 内法 241 前後なので、240 の布板が 1 枚。拡幅後の上層では、NDT03 のような 305 のつなぎ材（梁間方向）に 240 の布板 1 枚を掛け、桁行（1829 など）に渡すと読める。ブラケットの腕木の上に直接床を置く場合、Iq では杉足場板に限られる。
- 610 幅（日建 NDBK06H / 06HS / NHBK06H、Iq IQBH610、JFE JHBK-6）: 内法 546〜560 なので、500（実幅 490）の布板 1 枚、または 240 を 2 枚。信和の「600mm＝500,400mm幅踏板用」とも合う。
- 497 幅（Iq IQBHK497）: 上層 1107 のうち 497 が増えた分。Iq の 1107 幅では、布板の組み合わせ（490×2＋…など）で床が決まる。497 の帯だけを見れば、490 を 1 枚か 240 を 2 枚が入る寸法（推定）。ただしカタログは床材の枚数を書いていない。
- 隣り合うブラケットの間（桁行 1829 など）に布板を渡す使い方について、拡幅狭幅ブラケットは、布板を直接受ける部材としてより、上層の支柱を受ける部材として描かれている。上層の床は先端に立てた支柱のコマに付けた梁間方向の材に掛けると読める（推定）。張出ブラケット（Iq IQBH・信和 SBH・日建 NDBK06H）は、従来どおり腕木の上に床を置くか、先端ホゾに支柱を立てて手すりや布を付ける使い方。

### Gaps
- 「拡幅狭幅ブラケットの腕木そのものに布板（アンチ）を何枚載せるか」をはっきり書いたカタログは見つからなかった。Iq の 305 の注記が 497 にも当てはまるかも判断できない（注記は 305 の図の下だけにある）。
- 日建 ND の拡幅ブラケットの腕木に布板のフックが掛かるかどうかも記載がない（ND の拡幅例では NDT03 のつなぎ材を使っている）。
