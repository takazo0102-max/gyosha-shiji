## Tekla Structures の接合部（Component、ガセットの種類、AutoConnection、ルールの持ち方）

### Takeaway
Tekla は「どの接合を使うか」（AutoConnection）と「その接合の寸法」（AutoDefaults）を別のルールに分け、取り合いの種類ごとのツリーを上から見て最初に合った規則を使う。一括で入れても既存の接合は変えない。これが今回いちばん具体的な手本。

### Cited Findings
**ルールの構造**
- 階層はルールグループ → フレーミング条件 → ルールセット → 接合。ルールグループは規格・プロジェクト・メーカー・モデルごとに作る — 【公式・2025】[Define AutoConnection settings and rules](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)
- フレーミング条件は変更できない定義済みの取り合いで、梁-梁（ウェブ・フランジ）、梁-柱（ウェブ・フランジ）、梁の継手、柱の継手 — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)
- 最初に一致したルールセットを使う。制約の強いルールを上、汎用のルールを下に置き、Move up / Move down で順を変える — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)
- ルールの値は単一値か最小・最大の範囲で入れる — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)
- 設定はモデルの attributes フォルダの rules.zxt に保存し、プロジェクトや会社のフォルダへ写して他のモデルで使う — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)
- AutoConnection の二次部材は最大 2 つで、二次部材の多い複雑なガセットには使えない。第1・第2 の二次部材は断面の高さと ID 番号で決める — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)

**実行と例外**
- 手順は部材を選ぶ → Create AutoConnections → AutoConnection 用と AutoDefaults 用のルールグループを別々に選ぶ → Create connections — 【公式・2025】[Create a connection using AutoConnection](https://support.tekla.com/doc/tekla-structures/2025/det_getting_started_using_autoconnection)
- Advanced タブでフレーミング条件ごとに、接合を AutoConnection / None / 手で指定（Select）から、寸法を Autodefaults / No autodefaults から選べる — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/det_getting_started_using_autoconnection)
- AutoConnection を使うと接合ダイアログのプロパティは無視され、既存の接合は変更されない — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/det_getting_started_using_autoconnection)

**力によるルール**
- AutoDefaults は反力を、接合のプロパティ、次に二次部材のユーザー定義属性の順に探す。無ければ反力のルールは使えない — 【検索要約のみ・2022〜2024】[Using reaction forces and UDLs](https://support.tekla.com/fi/doc/sys_autoconnections_reaction_forces_and_udl)
- 反力が無いときは UDL の計算でせん断を見積もるが、主にヤード・ポンド系向けとされる — 【検索要約のみ】[同上](https://support.tekla.com/fi/doc/sys_autoconnections_reaction_forces_and_udl)

**ガセットの部品の例**
- Tube gusset (20) は 1〜10 本の中空ブレースを梁か柱に接合する。入力順は主部材 → ブレースを順に → 中ボタン — 【公式・2025】[Tube gusset (20)](https://support.tekla.com/doc/tekla-structures/2025/conn_20_help)
- Tube gusset (20) の部品はガセット、スティフナー2種、タング板、カバープレート2種、クリップアングル、コネクションプレート、エンドプレート、クロスプレート — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/conn_20_help)
- パラメータのタブは Picture（寸法・主部材平行かブレース平行か）、Gusset（厚さ・形状・主部材への接続方法・面取り・切り欠き）、Brace conn、Stiffeners、Gusset conn（ボルト群）、Brace bolts 1〜3、Cross plates — 【公式・2025】[同上](https://support.tekla.com/doc/tekla-structures/2025/conn_20_help)
- 隅のブレース接合は8種類。Corner tube gusset (56)、Corner bolted gusset (57)、Wrap around gusset (58)、同 中空用 (59)、同 cross (60)、Corner wrapped gusset (63)、Bent gusset (140、2本の曲げ線で折る)、Heavy brace (165、リブで補強) — 【公式・2024】[Corner bracing connections](https://support.tekla.com/doc/tekla-structures/2024/det_bracing_corner_bracing_conns)
- 隅の組み合わせは梁と柱、柱とベースプレート、梁と延長エンドプレート、2本の梁と1本の柱など — 【公式・2024】[同上](https://support.tekla.com/doc/tekla-structures/2024/det_bracing_corner_bracing_conns)
- ブレースの種類で Bolted gusset (11) と Tube gusset (20) を使い分ける — 【第三者・検索要約のみ】[20 Most Used Tekla Components](https://steelexplained.com/20-most-used-tekla-components/)
- ベースプレート系に Base plate (1004)、Stiffened base plate (1014)、U.S. Base plate (1047) がある — 【公式・検索要約のみ】[Improvements in components](https://support.tekla.com/cs/node/118836)

### Inferences
- 部材の組み合わせで分類（フレーミング条件）→ 条件の範囲で絞る → 先に合った規則を採る、という流れはそのまま JSON の表にできる。
- ガセットの種類は「途中か隅か」「ブレースの断面が中空か開断面か」「主部材への付け方」の3軸で整理されている。GDL 部品も3つの列挙パラメータで足りそう。
- 二次部材を2つまでに絞るのは Tekla の制約で、手本にしなくてよい。Tapir からの配置なら、1つの節点に集まる部材を全部読んで判定できる。

### Gaps
- Available rules の一覧（断面・材質・角度など）は読んだページに無かった。
- AutoDefaults の専用ページの本文は読んでいない。
- 既存の接合を置き換える操作の有無は読んだページに書かれていない。

## Revit の鋼構造接合部（Steel Connections for Revit、Advance Steel）

### Takeaway
Revit は接合の種類ごとに「適用範囲」をライブラリの情報として持たせ、Dynamo Player のスクリプトで配置する。ルールの材料は断面・鋼材の材質・部材の端部応力。Advance Steel は1か所で作った接合を他へ広げる（Propagate）やり方が手本になる。

### Cited Findings
- 接合部自動化は Structure / Steel タブの Connection パネルから開き、Dynamo Player にスクリプトの一覧が出る — 【公式・2025】[Library-Based Connection Design Automation](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-WhatsNew/files/GUID-0E348B44-A920-4577-B4A0-238241ECC8C4.htm)
- サンプルのルールは定義された適用範囲に基づいて配置し、適用範囲はライブラリに付く情報。地域の基準に合う定義済み接合の表を持つサンプルライブラリがあり、拡張できる — 【公式・2025】[同上](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-WhatsNew/files/GUID-0E348B44-A920-4577-B4A0-238241ECC8C4.htm)
- ルールは断面の特性・鋼材のグレード・部材の端部応力で接合の種類と部材を結びつける — 【公式・2022】[Associate Connections with Profile Sizes](https://help.autodesk.com/cloudhelp/2022/ENU/Revit-WhatsNew/files/GUID-817F1741-298D-4B92-B60D-0CE72D00A9A3.htm)
- 内容パックにアングル、シアエンドプレート、シート、柱の継手、ベースプレート、フィンプレートなどの接合が入る — 【公式・検索要約のみ】[Revit 2023 ブログ](https://www.autodesk.com/blogs/aec/2022/04/14/revit-2023-library-based-connection-design-automation/)
- 標準の鉄骨接合は 131 種類（2021 のヘルプ） — 【公式・検索要約のみ、古い版】[Standard Connections](https://help.autodesk.com/cloudhelp/2021/ENU/Revit-StructEng/files/GUID-FA242186-6216-40BA-9DC9-C2A347BE244D.htm)
- 自動化には全ての構造部材に解析部材が要る — 【検索要約のみ】[Revit 2023 ブログ](https://www.autodesk.com/blogs/aec/2022/04/14/revit-2023-library-based-connection-design-automation/)
- Advance Steel では接合を右クリックの Propagate Joint で他の柱へ広げ、ライブラリにも登録できる。Joint group で作る口もある — 【公式の講座・検索要約のみ】[Add connections and propagate them](https://www.autodesk.com/learn/ondemand/course/detailing-structural-models-steel/unit/1a7DI6NNrCLjoLoIKto89N)
- Connection Vault に「General bracings > Gusset plate to column and base plate」がある — 【フォーラム・検索要約のみ】[Gusset plate to column and base plate](https://forums.autodesk.com/t5/advance-steel-forum/gusset-plate-to-column-and-base-plate/td-p/7755274)
- 鋼管斜材のガセットには専用の接合が無い場合があり、他の接合を組み合わせて対応する — 【公式サポート・検索要約のみ】[How to design the connection with gusset plate and tab plate](https://autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-design-the-connection-with-gusset-plate-and-tab-plate-in-tube-diagonal-in-Advance-Steel.html)

### Inferences
- Tekla は規則の側に条件を持ち、Revit は接合の種類の側に適用範囲を持つ。自作ツールは符号表の行に範囲を持たせる形なら、どちらの考えでも読みやすい。
- 「1か所を手で決めて、同じ符号に広げる」は表を書かずに済む入口になる。

### Gaps
- 「Libraries with Steel Connections and Attached Ranges of Applicability」の本文は読んでいない。
- 2022 と 2025 のページは新機能の案内で、ルールの書式までは書かれていない。

## 日本の鉄骨専用 CAD（REAL4、KAP、すけるTON、FAST、SEEDS）

### Takeaway
公開ページで分かるのは「接合の決まりを先に登録し、自動で生成する」という大枠まで。符号と接合リストの持ち方、ブラケットの入力手順は、どの製品も公開ページに無い。

### Cited Findings
**S/F REAL4（データロジック）**
- 構造データの読み込みは SS3 と ST-Bridge、出力は 3D-DWG と IFC（IFC2x3・IFC4・IFC4.3）。IFC の入力は未対応 — 【公式】[REAL4](https://www.datalogic.co.jp/real4/)
- 寄棟など複雑な勾配の取り合いのガセットも作図できる — 【公式】[同上](https://www.datalogic.co.jp/real4/)
- S/F Liner からの変換では仕口の設定は変換されず、再設定が要る — 【公式】[同上](https://www.datalogic.co.jp/real4/)
- REAL4 のデータに NC、見積積算、生産計画、出荷計画、出来高管理、原価管理などが連動する — 【販売店】[S/F Real4 シンテック](https://shintech.jp/cad/Real4/)
- 開発元はデータロジックとする資料が多い（[公式](https://www.datalogic.co.jp/real4/)、[steelnavi](https://steelnavi.jp/bim-topic-3)）が、[conshift](https://conshift.net/tool/real4/) は提供元を別の会社名とする（検索要約のみ、食い違いあり）。

**KAP（日本ファブテック）**
- 1972 年から開発。「3000種を超える加工マクロ」と一括処理で大型物件に対応 — 【公式】[KAP 日本ファブテック](https://www.j-fab.co.jp/technology/iron/kap/)
- 入力とモデル化を別の処理にし、パーツは 4,000 種類以上（検索・お気に入りあり）— 【公式】[KAP システム](https://www.kapsystem.jp/)。上の「3000種」は加工マクロ、こちらはパーツで、数え方が違う可能性がある
- ブレース端部の形はメニューで選ぶ。梁とブレースを兼用するガセット形状にも対応 — 【公式】[KAP INPUT](https://www.kapsystem.jp/about/input)
- 方杖、デッキ受け、嵩上げ材、吊りピース、下がり止めピース、親綱掛けピース、ネットフック、スタンションを条件設定で自動配置する — 【公式】[同上](https://www.kapsystem.jp/about/input)

**FAST ZERO（ファーストクルー）**
- 2023 年 6 月発売。階・通り・部材種別ごとに複数人で分担して入力できる — 【公式】[FAST ZERO](https://fastcrew.co.jp/product/fast-zero/)、[プレスリリース](https://prtimes.jp/main/html/rd/p/000000002.000091444.html)（後者は検索要約のみ）
- 継手（スプライスプレート、ガセットプレートなど）と仕口（ダイヤフラム、パネル材など）の設計ルールを FAST ZERO 側のマスターに登録し、連携時に Revit 上へ接合部を自動生成する — 【公式】[FAST ZERO for Revit](https://fastcrew.co.jp/product/fast-zero-for-revit/)
- 製品単位でアセンブリ化し、製品名や重量の属性を付ける。梁中央材とブラケットの生成方法はアドインで選べる — 【公式】[同上](https://fastcrew.co.jp/product/fast-zero-for-revit/)
- 詳細化したモデルは建て方計画や仮設計画に使える — 【公式】[同上](https://fastcrew.co.jp/product/fast-zero-for-revit/)

**すけるTON（カルテック）**
- 構造パックは一貫計算の ST-Bridge を読み、鉄骨と基礎、詳細部材を自動で作る。仕口と継手は事前設定に従って図面に出る。一括変更もできる — 【公式】[すけるTON 構造パックの流れ](https://caltec.co.jp/product/skeleton_kozo/flow.html)
- 自動生成はガセットプレート、リブ、スプライスプレート、ダイヤフラム、ボルト。出力に継手リストを含む — 【公式】[構造パック概要](http://www.caltec.co.jp/product/skeleton_kozo/gaiyou.html)
- 積算版は部材長さ、重量、溶接長、塗装面積、耐火被覆、裏当て金、ボルト本数を出す — 【公式】[すけるTON 製品概要](https://www.caltec.co.jp/product/skeleton/gaiyou.html)
- Revit 上で継手と仕口を生成した事例（大和ハウス工業）がある — 【第三者・検索要約のみ】[すけるTONシリーズ活用](http://it.kensetsu-plaza.com/cad/example/3237)

**その他**
- 鉄工所の主要 CAD の比較は [steelnavi](https://steelnavi.jp/bim-topic-3) に一覧がある（REAL4・KAP・FAST ZERO・Tekla）— 【第三者】
- Mr.フレームWIN は基本寸法の入力でガセットを図面の任意の位置に置く — 【検索要約のみ】[mono.ipros](https://mono.ipros.com/product/detail/2000021354)

### Inferences
- REAL4・すけるTON に加え、後の節の GLOOBE も ST-Bridge を読む。符号と断面の入口として標準に近い（複数の製品の記載からの推定）。
- 「マスターを先に決める → 主材を読む → 接合を生成する → 違う所を直す」が国内製品の共通の順番と見られる。公開ページは大枠しか書いていないので、細かい運用は推測。
- KAP の自動配置の項目のうち、吊りピース・親綱掛けピース・ネットフック・スタンションは、ashiba の親綱や足場と直接つながる。仮設側のツールならではの増分になる。

### Gaps
- 符号と継手リストの具体的な持ち方、ブラケットの入力手順は、どの製品も公開ページに無かった。マニュアルは一般公開されていない様子で、デモか販売元に聞かないと分からない。
- SEEDS は鉄骨 CAD としての資料が見つからなかった。製品名の確認が要る。
- すけるTON の機能一覧（detail.html）は読んでいない。BSIJ の製品シート（[PDF](https://www.bsij.or.jp/reporting/data/info_sheet_0001.pdf)）は本文が読めなかった。検索要約では「仕口・継手の自動生成と個別入力」とあるが、未確認。
- 竹中工務店の S/F ユーザー会資料（[PDF](http://www.datalogic.jp/real4/swfu/excel/haihushiryou.pdf)）は開いていない。検索要約では、ゼネコンが接合部の説明書をファブに支給する運用が紹介されている。

## GLOOBE と Archicad（標準のコネクション、鉄骨機能、アドオン）

### Takeaway
GLOOBE Construction は柱脚の詳細入力と節・ピースの重量算出を持つが、ガセットの機能は公開ページで確認できなかった。Archicad は標準の鉄骨断面までで、接合部の専用機能やアドオンは見つからず、IFC で鉄骨側と受け渡す使い方が中心。

### Cited Findings
**GLOOBE**
- 鉄骨柱脚はベースプレートとアンカーボルトを含めて入力でき、専用の柱脚編集ダイアログとアンカーフレームのモデル化がある — 【公式】[躯体計画](https://archi.fukuicompu.co.jp/products/gloobe_c/frame.html)
- 各種部材入力に継手とダイアフラムが挙がる。鉄骨との関係の説明は無い — 【公式】[同上](https://archi.fukuicompu.co.jp/products/gloobe_c/frame.html)
- 鉄骨の概算数量を集計し、根拠を平面図や 3D で確認できる。ST-Bridge からリストを取り込める — 【公式】[同上](https://archi.fukuicompu.co.jp/products/gloobe_c/frame.html)
- GLOOBE 2026 は 2026 年 7 月 8 日リリース。足場部材の拡充、単管・壁つなぎの編集、配筋の 3D モデル化が報じられ、鉄骨と揚重の記述は無い — 【第三者】[bi-media](https://bi-media.jp/4397/)、[プレスリリース転載](https://www.the-miyanichi.co.jp/pressrelease/prtimes/824837.html)（後者は検索要約のみ）

**Archicad**
- 標準鉄骨の断面は［オプション］→［断面形状］からインポートする — 【公式・古い版 AC23】[標準鉄骨柱/梁の断面形状の使用](https://help.graphisoft.com/AC/23/JPN/_AC23_Help/040_ElementsVB/040_ElementsVB-57.htm)
- 既定のライブラリに無い部品は BIMcomponents.com を探す案内がある — 【公式・検索要約のみ】[ライブラリに欲しいオブジェクトが無い場合](https://support.graphisoft.co.jp/hc/ja/articles/360026053273-%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA%E3%81%AB%E6%AC%B2%E3%81%97%E3%81%84%E3%82%AA%E3%83%96%E3%82%B8%E3%82%A7%E3%82%AF%E3%83%88%E3%81%8C%E7%84%A1%E3%81%84%E5%A0%B4%E5%90%88)
- Archicad のモデルを IFC で書き出し、Tekla で詳細化する流れが一般的に紹介される — 【第三者・検索要約のみ】[OpenBIM実務の進め方](https://www.capa.co.jp/archives/52200)
- 竹中工務店は Revit の IFC を Tekla へ変換する自社仕様を作り、仕口納まりは Tekla で配置した — 【第三者・検索要約のみ】[建設通信新聞](https://www.kensetsunews.com/web-kan/1024760)

### Inferences
- Archicad 上で符号表から接合部を一括で入れる市販の手段は見つからなかった。見つからないことは無いことの証明ではないが、自作する余地はある。
- GLOOBE の柱脚編集のように、ベースプレート・アンカー・アンカーフレームを1つの窓にまとめる形は、ashiba の部品の窓の作りに合う。

### Gaps

- GLOOBE のガセット機能は確認できなかった。新機能動画（[施工詳細](https://www.youtube.com/watch?v=01LLJ9MxFWw)）は見ていない。

## 建て方計画の機能（節ごとの重量、ピース重量表、順序のシミュレーション）

### Takeaway
順序の持ち方は Tekla Construction Sequencer が最も具体的で、Order と Sub Order の番号に、種別の順と Z→X/Y の並べ替えで自動採番する。節・ピースの重量は GLOOBE が公式に掲げる。smartCON Planner は建て方専用機能でなく、ステップ図と選択部材の重量合計、クレーンの定格総荷重の組み合わせで使う。

### Cited Findings
**Tekla**
- 計画モードと表示モードがあり、事務所で順序を計画して現場へ渡し、同じ道具で表示と進捗を見る — 【公式】[Construction Sequencer](https://support.tekla.com/help/tekla-structures/not-version-specific/construction_sequencer)
- Order が同じ部材は同時に動く。Sub Order は地上の先組みなど部分の順序に使い、Renumber で連番を振る — 【公式】[同上](https://support.tekla.com/help/tekla-structures/not-version-specific/construction_sequencer)
- Automatic Order は柱・梁・ブレースなどの選択フィルタを順に並べたルールセットを名前をつけて保存し、Z（低い方から）→ X または Y（原点に近い方から）で並べる — 【公式】[同上](https://support.tekla.com/help/tekla-structures/not-version-specific/construction_sequencer)

## 一括で入れる手順で共通する考え方（符号表＋ルール＋例外の上書き）

### Takeaway
どの製品も「取り合いの種類 → 条件に合う規則 → 寸法の既定値 → 個別の上書き」の4段で、規則はモデルの外のファイルか部品のマスターに持つ。再実行で手直しを壊さない仕組みが要る。

### Cited Findings
| 段階 | Tekla | Revit | 国内 CAD |
|---|---|---|---|
| 規則の置き場 | ルールグループ、rules.zxt（[公式](https://support.tekla.com/doc/tekla-structures/2025/sys_autoconnections_ac_setup)） | ライブラリの適用範囲（[公式](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-WhatsNew/files/GUID-0E348B44-A920-4577-B4A0-238241ECC8C4.htm)） | FAST ZERO のマスター（[公式](https://fastcrew.co.jp/product/fast-zero-for-revit/)）、すけるTON の事前設定（[公式](https://caltec.co.jp/product/skeleton_kozo/flow.html)） |
| 判定の材料 | フレーミング条件＋ルールセット（単一値か範囲） | 断面・材質・端部応力（[公式](https://help.autodesk.com/cloudhelp/2022/ENU/Revit-WhatsNew/files/GUID-817F1741-298D-4B92-B60D-0CE72D00A9A3.htm)） | KAP の条件設定（[公式](https://www.kapsystem.jp/about/input)）。他は非公開 |
| 寸法の既定値 | AutoDefaults（[公式](https://support.tekla.com/doc/tekla-structures/2025/det_getting_started_using_autoconnection)） | 定義済みの接合の表 | マスターの中と見られる（推定） |
| 例外 | 実行時に条件ごとに None・手で指定。既存の接合は不変（[公式](https://support.tekla.com/doc/tekla-structures/2025/det_getting_started_using_autoconnection)） | 接合の種類の複製・編集（検索要約のみ） | すけるTON の変更・一括変更（[公式](https://caltec.co.jp/product/skeleton_kozo/flow.html)） |
| 流用 | rules.zxt を写す | ライブラリの拡張 | REAL4 は S/F Liner から仕口設定が移らない（[公式](https://www.datalogic.co.jp/real4/)） |

### Inferences
以下は調査からの提案で、どの製品の記述でもない。

1. **接合の表を2枚に分ける。** 「どの接合か」（取り合い×条件）と「その寸法」（符号や断面の範囲）を分ける。今の steel_run.py は --gp-w と --gp-t の全体で1つの値なので、ここを符号ごとに変える。
2. **取り合いの種類を固定する。** 柱脚、柱の継手、大梁の継手、ブラケット（柱-梁）、ブレースの隅、ブレースの途中、ブレースの交差。
3. **上から見て最初に合った行を採る。** 符号の完全一致を上、断面の範囲を中、既定値を下に置く。どの行で決まったかを表に出すと確かめやすい。
4. **例外は別の層にする。** 節点ごとに「なし」「別の接合」「寸法だけ変える」を持ち、再実行でも残す。Tekla の既存不変に当たる。
5. **寸法の根拠を印で分ける。** 構造図の値と【目安】を列で区別する。ashiba の方針（出典つきの実値）にも合う。
6. **ガセットの部品は3軸の列挙にする。** 途中か隅か、ブレースの断面、主部材への付け方。複数のブレースが1枚に集まる形も持てるようにする。
7. **入口は段階的に。** まず窓と表、次に ST-Bridge の読み込みを検討する（ST-Bridge の読み込みの手間は調べていない）。
8. **仮設の増分。** KAP の条件配置を手本に、吊りピースや親綱掛けピースも規則で置く。

### Gaps
- 国内 CAD の例外の持ち方は公開資料に無い。
- 再実行のとき、手直しした接合をどう照合するかの実装の詳細は、どの製品も公開していない。ashiba は placed_parts.json に GUID を持つが、節点のキーの作り方は別に決める必要がある。
