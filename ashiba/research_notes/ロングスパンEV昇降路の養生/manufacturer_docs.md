# ロングスパン工事用エレベーターの昇降路の囲い・養生・防護（メーカー・レンタル会社の資料と、その元になる構造規格）

調査日 2026-10-28。WebSearch／WebFetch と、PDF は pdftotext で本文を確認。
**全体の結論を先に書く**: メーカーやレンタル会社の取扱説明書・組立要領書（昇降路の囲い、乗場、シート、風荷重を書いた章）は Web 上で一つも読めなかった。三成研機のカタログ PDF は全部 404、中央ビルト工業の解説は本文が PDF のダウンロード形式で読めなかった。公開ページにあるのは仕様（積載・揚程・壁つなぎ間隔）と、構造規格の写しまで。昇降路の養生について一番具体的なのは、厚労省の**エレベーター構造規格の本文**と、国交省の**建設工事安全マニュアル（リフト工）**。

## 1. 各社の資料は昇降路の防護について何を書いているか（北川鉄工所・三成研機・日建リース・エスアールエンジ・建機サービス・スギコ・三葉工業・タカミヤ ほか）

### Takeaway
公開されている製品ページ・カタログに、昇降路の外周の囲い、金網、乗場扉、シートについての記述は**見つからなかった**。レンタル会社の日建リースと中央ビルト工業は構造規格を引いて囲いを説明しているが、ロングスパン機には適用されない第16条の要件を、ロングスパン機の基準として載せている（2. の食い違いを参照）。

### Inferences

## 2. 全高の囲いは必要か、地上部の囲いだけか。昇降路の落下物防止の記述はあるか

### Takeaway
**現行のエレベーター構造規格では、昇降路の壁・囲い・出入口の戸を定めた第16条は、ロングスパン工事用エレベーターには適用されない**（条文が「ロングスパン工事用エレベーター以外のエレベーターには」と書いている）。法令上は全高の囲いも地上部の囲いも求められていない。囲いを求めているのは国交省の安全マニュアルで、「作業員及び長尺の資材等が昇降路内に入らないように養生囲いを設ける」としている。囲う範囲と高さは数値で決めておらず、「設置場所周辺の作業内容を考慮し」とだけ書いている。

### Cited Findings
- 構造規格 第16条（昇降路の構造）本文: 「工事用エレベーターであって、搬器として長さ三メートル以上の荷台を使用し、定格速度が〇・一七メートル毎秒以下のもの（以下「ロングスパン工事用エレベーター」という。）**以外の**エレベーターには、次に定めるところにより、昇降路を設けなければならない。」 各号は「一 出入口…及び人が近づくおそれのない部分を除き、壁又は囲い」「二 出入口に戸」「三 同時に二以上の出入口の戸が開かない構造」など。第2項は壁・囲い・戸を難燃材料とする — [エレベーター構造規格（厚労省 法令等データベース）](https://www.mhlw.go.jp/web/t_doc?dataId=74025010&dataType=0&pageNo=1)
  - **食い違い**: [日建リース](https://nikken-lease.co.jp/nikken-sales/longev/)と[中央ビルト工業](https://www.chuo-build.co.jp/column/?itemid=89&dispmid=457)は、この第16条の囲い要件（と「床面から1.8m以上・足場のない部分」の解釈）を、ロングスパン機の設置基準として載せている。条文を読む限り、ロングスパン機は適用除外。
- 日本建設機械施工協会（JCMA）の解説「2.4.1 工事用エレベータ」: ロングスパン機は「工事用エレベータと比較して、昇降路の囲い、出入口扉、搬器床面積等の規制が緩和されている」「搬器荷台の手摺、昇降路扉の基準が緩和されている」。主に低層（5F〜15F 程度、別の箇所では 4F〜10F）で長尺物を運ぶ。荷台は 0.9m ごとに長さを変えられるものが主流 — [JCMA 2.4.1 工事用エレベータ PDF](https://www.jcmanet.or.jp/kikaibukai/kenchiku/pdf2/020401.pdf)
- 国交省「建設工事安全マニュアル」リフト工（工事用リフト・工事用エレベータ）の 2.設置時の注意（1）設置計画:
  - 「作業員及び長尺の資材等が昇降路内に入らないように養生囲いを設ける。」
  - 「昇降路の囲いについては、建設用リフト構造規格、エレベータ構造規格に定められているが、設置場所周辺の作業内容を考慮し、作業員及び長尺の資材等が昇降路内に入らないように養生囲いを設ける。」
  - 「リフトの荷台から荷物が落下、飛散しないような措置を講ずる。」「水平堅固な地盤面に設置し、壁つなぎを確実に取り、倒壊、落下が無いように十分注意する。」
  - 組立て時:「組立て作業場所周辺、開口部はネット養生を行い、下部はロープ看板にて立入禁止措置を行う。」
  - 使用時:「荷台の落下、揚重物の落下・飛散などの防止措置を講ずる。又、搬器の昇降及びワイヤロープの走行により作業員の危険が生ずる恐れのある箇所は、囲いを設け立入禁止とする。」「ロングスパン工事用エレベータに作業員を搭乗させる場合は、定員を遵守しその搭乗範囲に堅固なヘッドガードと積載物との遮断設備を設ける。」
  - 災害例への対策:「搬器挟まれ」は鍵がなければ外から開けられない装置・搬器の囲い板・開閉の安全装置の確認、「昇降路挟まれ」は「搬器には積荷が崩れても外側にはみ出さない囲いを設ける」
  - 以上すべて [国交省 建設工事安全マニュアル リフト工 PDF](https://www.mlit.go.jp/sogoseisaku/kensetsusekou/kankyou/mic/safe_manual/03_14_liftkou.pdf)
- 構造規格 第21条第2項（ロングスパン機の搬器）: 搭乗席の周囲に高さ 1.8m 以上の囲い（搭乗席以外の部分と接する箇所は遮断設備で代えられる）、搭乗席に落下物に対する堅固なヘッドガード、搭乗席以外の部分に高さ 90cm 以上の堅固な手すりと中さん・幅木 — [エレベーター構造規格](https://www.mhlw.go.jp/web/t_doc?dataId=74025010&dataType=0&pageNo=1)（第21条第2項の各号は WebFetch の要約で確認。項の冒頭「前項の規定にかかわらず、ロングスパン工事用エレベーターの搬器は」は本文で確認）
- 現場の事例（厚労省 安全コンクールの作品。検索スニペットのみ、ページは 404 で本文は未確認）: 仮設エレベーターの昇降路と周りの足場を「金網・メッシュシート及びシャッターゲート」で区画し、シャッターゲートを開けるとリミットでエレベーターが動かない。目的は「竪穴区画として上下作業及び落下物による事故、機械との巻込み事故を防ぐ」— [anzeninfo 安全コンクール 2014 n093](https://anzeninfo.mhlw.go.jp/anzenproject/concour/2014/sakuhin3/n093.html)（機種がロングスパン機かどうかは不明）
- 参考（常設・一般の昇降機向け）: 佐賀労働局のリーフレットは「昇降路は荷の積卸口を除き壁が設けられていること」「荷の積卸口に戸」「全ての荷の積卸口の戸が閉じていない場合には、搬器を昇降させることができない装置」「囲いは指などが入るような隙間があるものは避ける」を挙げ、根拠をエ構16条・30条としている。ロングスパン機は第16条の適用外なので、そのまま当てはめることはできない — [佐賀労働局 リーフレット PDF](https://jsite.mhlw.go.jp/saga-roudoukyoku/content/contents/002495149.pdf)

### Inferences
- 全高の囲いや金網は、法令（構造規格）にもメーカーの公開資料にも求める記述が無い。求めているのは国交省マニュアルの「養生囲い」。その範囲（地上だけか、足場のある全層か）は数値で決まっておらず、現場判断（周辺の作業内容）に任されている。
- ロングスパン機で人と物を守る仕組みは、昇降路の囲いではなく**搬器側**に置かれている（搭乗席の 1.8m 囲い＋ヘッドガード、荷台の 90cm 手すり＋中さん＋幅木、遮断設備のインターロック＝第32条第4号）。
- ashiba で昇降路の外周をシートで囲うのは「養生囲い」（長尺物の進入防止・落下物防止）の位置づけになり、法令が求める囲いではない、と整理できる（推測）。

### Gaps
- 地上部の囲いの高さ（1.8m 等）を**ロングスパン機について**数値で定めた一次資料は見つからなかった。「1.8m」は第16条の解釈（ロングスパン機は適用外）と、第21条の搭乗席の囲いの高さに出てくる数値。
- 第16条の除外が平成15年の改正（厚労告8）の前からあったのか、改正で変わったのかは確認できていない。平成5年 基発第626号（解釈例規）のページは証明書のエラーで読めなかった。
- 昇降路の落下物防止を明記したメーカーの資料は見つからなかった。

## 3. 乗場の扉・フロアーゲート・開閉式手すりとインターロック

### Takeaway
ロングスパン機は第30条第3項で、戸が閉じていないと昇降できない装置（第30条第1項第2号）を備えなくてよい。代わりに第32条第4号で「遮断設備が設けられているものにあっては、遮断設備が閉じていない場合には、搬器を昇降させることができない装置」を求めている。乗場（各階）のゲートについて、メーカーの仕様記述は見つからなかった。

### Cited Findings
- 第32条（ロングスパン工事用エレベーターの安全装置）: 一 昇降を知らせる警報装置（安全上支障がなければ省略可）、二 傾きを矯正できる装置、三 傾きが 1/10 を超えないうちに動力を自動で遮断する装置、四 「遮断設備が設けられているものにあっては、遮断設備が閉じていない場合には、搬器を昇降させることができない装置」、五 走行式は最下部でなければ走行できない装置 — [エレベーター構造規格](https://www.mhlw.go.jp/web/t_doc?dataId=74025010&dataType=0&pageNo=1)
- 第30条第3項: 「ロングスパン工事用エレベーターは、同項第二号及び第五号に掲げる装置を備えないことができる。」 第2項で、工事用エレベーターは第1号・第9号・第10号・第11号の装置も省略できる — [エレベーター構造規格](https://www.mhlw.go.jp/web/t_doc?dataId=74025010&dataType=0&pageNo=1)（WebFetch の要約による。各号の正確な文言は本文で再確認が望ましい）
- 金子機械製作所の機種は「手摺りリミットスイッチのロック不良」を停止原因としてモニタランプに表示する。搬器の手すり（開閉式）にリミットスイッチがあることがわかる — [金子機械製作所](http://kanekokikai.jp/pages/20/)
- 日本マーツ PowerCARGO:「荷台部の伸縮式ゲートは上下で支持」 — [日本マーツ IPROS](https://mono.ipros.com/product/detail/2000580231)
- ashiba では、建機サービスの図面から「フロアーゲート」を機種表の項目として扱っている（利用者が持っている資料。docs/開発計画.md 14-1）。Web では確認していない。

### Inferences
- ロングスパン機のインターロックは主に**搬器側の手すり・遮断設備**で、乗場ゲートとの連動は法令上必須ではない。フロアーゲート（各階の開閉柵）は、足場側の墜落防止として付ける付属品になる（推測）。

### Gaps
- 地上部の囲いの扉と運転回路のインターロックを書いたメーカーの資料は見つからなかった。

## 4. 搬器と周りの構造物・足場・壁つなぎ・シートのあき（すき間）

### Takeaway
数値の基準は構造規格第23条だけ。昇降路の出入口の床先と搬器の床先の間隔は 4cm 以下（工事用は安全上支障がなければ適用外）。昇降路壁と搬器の出入口の床先の間隔は 12.5cm 以下（安全上支障がなければ適用外）。搬器の外周と足場・シートの**最小あき**を定めたメーカーの資料は見つからなかった。

### Cited Findings
- 第23条（床先の間隔）: 「昇降路の出入口の床先と搬器の出入口の床先との間隔は、四センチメートル以下でなければならない。ただし、工事用エレベーターについては、安全上支障がない場合には、この限りでない。」「２ 昇降路壁と搬器の出入口の床先との間隔は、十二・五センチメートル以下でなければならない。ただし、安全上支障がない場合には、この限りでない。」 — [エレベーター構造規格](https://www.mhlw.go.jp/web/t_doc?dataId=74025010&dataType=0&pageNo=1)
- 中央ビルト工業は、ロングスパン機の設置基準として同じ 4cm／12.5cm を挙げ、数 cm のずれで床と当たるおそれがあるので逃げ墨・下げ振りで据えるよう書いている — [中央ビルト工業 コラム](https://www.chuo-build.co.jp/column/?itemid=89&dispmid=457)
- 壁つなぎ間隔（マストを建物・足場に留める間隔）: 光洋 PowerCARGO 3m（構造物と仮設足場間、60m まで）— [光洋機械産業](https://pr.www.ipros.com/kyc/product/detail/2000887361)。金子機械 4m 以内（枠組足場で取付可）— [金子機械製作所](http://kanekokikai.jp/pages/20/)
- 日建リースのカタログ図に「衝突防止装置」と寸法（195・70・265 等）がある。何との衝突を防ぐものかは、図のテキストからは判読できない — [日建リース カタログ p.48](https://nikken-lease.co.jp/nikken-sales/wp-content/uploads/2019/11/nikkencatalog2018_53.pdf)

### Inferences
- シートの位置を縛る数値は、乗場の床先 4cm／12.5cm（出入口側）だけ。出入口以外の搬器の側面と足場・シートの間には法令の数値が無い。搬器の手すり・荷のはみ出しが当たらない寸法（荷台幅＋手すり＋余裕）で決めることになる（推測）。

### Gaps
- 搬器の外面と足場の建地・壁つなぎ・シートの最小あき（例: 100mm 以上）を書いたメーカーの組立要領書は見つからなかった。

## 5. 昇降路まわりのシート・ネット、マストにシートを付けたときの風荷重

### Takeaway
「マストにシートを付けてはいけない」「シートは足場側にだけ付ける」という明示の記述は、**どのメーカー資料にも見つからなかった**。公的な資料にあるのは、国交省マニュアルの「組立て作業場所周辺、開口部はネット養生」と、安全コンクールの事例の「金網・メッシュシートで区画」まで。

### Cited Findings
- 「組立て作業場所周辺、開口部はネット養生を行い、下部はロープ看板にて立入禁止措置を行う。」 — [国交省 リフト工 PDF](https://www.mlit.go.jp/sogoseisaku/kensetsusekou/kankyou/mic/safe_manual/03_14_liftkou.pdf)
- 昇降路と足場の区画を金網・メッシュシートで行った事例（検索スニペットのみ）— [anzeninfo 安全コンクール 2014 n093](https://anzeninfo.mhlw.go.jp/anzenproject/concour/2014/sakuhin3/n093.html)
- シート付き足場の風荷重は、壁つなぎの軸力に着目した風洞実験で研究されている（足場の研究で、エレベーターのマストの研究ではない）— [労働安全衛生総合研究所 SRR-No31-2](https://www.jniosh.johas.go.jp/publication/doc/srr/SRR-No31-2.pdf)（検索スニペットによる）

### Inferences
- マストの壁つなぎ間隔（3m・4m 以内）は、メーカーがシート無しのマスト単体で決めた値と思われる。マストにシートを留めると受風面積が増えるため、メーカーへの確認が要る項目として扱うのが妥当（推測。根拠になる一次資料は無い）。

### Gaps
- マストへのシートの取付けの可否と風荷重の扱いは、メーカー・レンタル会社のどの公開資料にも記述が無かった。取扱説明書（非公開）を取り寄せるか、メーカーに問い合わせる必要がある。
