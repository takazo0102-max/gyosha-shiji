# 仮設工事の金額のための単価（出典つき）

調べた日: 2026-11-04。目的は、ashiba が置いた仮設の数量と工程表の日数（`research_notes/工程表 歩掛かり/歩掛かり.md`）から、仮設の金額の概算を出す単価表を作ること。

- 値は出典の表から写した。出典に無いものは「見つからない」と書いた。近い公開値を使うものは【目安】と付けて理由を書いた。
- 頁は **PDF の頁（開いたときの通し番号）** と、あれば **印刷の頁番号** を並べた。
- PDF は WebFetch で読んだ（ツールが一時保存した控えを pdftotext で読んだ）。プロジェクトには保存していない。
- 金額はすべて **税抜**（出典の表記どおり。税込のものはそう書いた）。

## 0. まず知っておくこと（公開されない値がある理由）

公共工事の仮設材の賃料・建設機械の賃料は、積算基準そのものが **「物価資料（月刊 建設物価・月刊 積算資料・季刊 建築コスト情報・季刊 建築施工単価）の掲載価格による」** と決めている（国交省 公共建築工事標準単価積算基準 R8 第1編 総則 S1 頁「ニ．仮設材費」、第2編 A1 頁「仮設資材賃料は、物価資料による仮設資材賃料（基本料＋日額賃料×設計供用日数）」）。物価資料は有料の刊行物で著作権があるため、**都道府県の公表単価表では賃料の欄が黒塗り・空欄**になっている（福島県・大分県・福岡市・新潟県で確認）。

そのため、

1. **労務単価・共通費の率** は国の公開資料で東京の値がそろう（§1・§5）。
2. **東京都の工事設計単価表** は「物価資料に載らない品目」だけを公開しており、仮設では **くさび緊結式足場（材工共・存置月数別）・出入口ゲート・仮設ゲート・防音シート掛払い手間・横矢板設置・ラフター100t 賃料** などが取れる（§2・§3・§4）。
3. **枠組足場・敷鉄板・仮囲いの賃料（基本料・日額）** は、**金額を入れて公表された設計書**（徳島県）と **リース会社の公開価格** を【目安】として使うしかない（§2・§6）。

### 利用条件の注意（ツールに値を同梱するとき）

- **T（徳島の設計書）**: 冒頭に「設計書の公表により知り得た情報は … ダウンロードを行った個人又は法人における１次利用に限るものとし、… 第三者への提供行為を行わないこと」とある。**この値を ashiba の既定値として配布・販売物に入れない**。社内の物差しにとどめ、利用者が自分の単価を入れる形にする。
- **O（大分）・F（福島）**: 「販売目的のための複写（複製、転載、磁気データ作成等）を禁止」「二次的著作物の作成を禁止」とある。同じく配布物に同梱しない。
- **L・C・K（国交省）**: 国交省ホームページの利用ルール（https://www.mlit.go.jp/link.html ）による。基準の式・係数・労務単価は既定値に使いやすい。
- 東京都（TZ・TJ・TG）は利用条件の記載を見つけていない。配布前に確認する。

### 2-5. 自分で組むときの式（国の基準）

出典 K（総則 S1〜S4、表A1-1-10 A4 頁）。

```
足場の金額 ＝ 掛面積 ×｛掛払い手間 ＋ 基本料 ＋ 日額賃料 × 設計供用日数 ＋ 修理費 ＋ 運搬｝
  掛払い手間 ＝ とび工の人数／㎡ × 労務単価 ×（1＋専門工事業者の諸経費率 42〜52％）
  修理費     ＝ 仮設資材賃料の 5％（K A1「ホ．修理費」）
  材料の賃料 ＝ Σ（部材の数量／㎡ ×（基本料 ＋ 日額 × 日数））×（1＋諸経費率 9〜13％）
```

- 専門工事業者等の諸経費の率: **労務費 42〜52％、材料費等 9〜13％**（K 表3、S4 頁）。

## 5. 共通仮設費率と、共通仮設・直接仮設の区分

出典 C（公共建築工事共通費積算基準 R8、印刷 p3〜9）。

### 5-1. 共通仮設費率（直接工事費に対する％、一般的な市街地）

```
Kr ＝ Exp( a − b × ln P ＋ c × ln T )      Kr: 共通仮設費率(%)（小数第3位四捨五入で2位止め）
                                         P: 直接工事費（千円、処分費を含まない）  T: 工期（か月）
```

| 別表 | 工事 | a | b | c | P の範囲（千円） |
|---|---|---|---|---|---|
| 別表-1 | 新営建築工事 | 3.346 | 0.282 | 0.625 | 10,000 ≦ P ≦ 5,000,000 |
| 別表-2 | 改修建築工事 | 3.962 | 0.315 | 0.531 | 3,000 ≦ P ≦ 1,000,000 |
| 別表-3 | 新営電気設備工事 | 3.086 | 0.283 | 0.673 | 10,000〜1,000,000 |
| 別表-4 | 改修電気設備工事 | 1.751 | 0.119 | 0.393 | 3,000〜1,000,000 |
| 別表-5 | 新営機械設備工事 | 2.173 | 0.178 | 0.481 | 10,000〜1,000,000 |
| 別表-6 | 改修機械設備工事 | 2.478 | 0.173 | 0.383 | 3,000〜1,000,000 |
| 別表-7 | 昇降機設備工事 | 4.577 | 0.323 | （T なし） | 5,000〜500,000 |

- 例（新営建築、計算）: P＝1億円・T＝8か月 → 4.05％、P＝5億円・T＝12か月 → 3.32％、P＝10億円・T＝15か月 → 3.13％。
- 範囲外は「別途定めることができる」。

### 5-2. 現場管理費率・一般管理費等率（参考）

```
現場管理費率（新営建築、別表-8）: Jo ＝ Exp(5.899 − 0.447 × ln Np ＋ 0.831 × ln T)   Np: 純工事費（千円） 10,000〜5,000,000
             （改修建築、別表-9）: Jo ＝ Exp(7.079 − 0.538 × ln Np ＋ 0.773 × ln T)   3,000〜1,000,000
一般管理費等率（別表-15）: 工事原価 3百万円以下 20.11％、3百万円超〜30億円 Gp ＝ 32.597 − 3.591 × log10(Cp)（Cp 千円）、30億円超 9.34％
```

### 5-3. 共通仮設費率に **含まれる** もの・**含まれない** もの（建築工事、C 表-1・表-5）

| 項目（表-1 の内容） | 率に含む（表-5） | 率に含まず積み上げ（ashiba で金額を出す対象） |
|---|---|---|
| 準備費 | 敷地整理（新営）、道路占有の準備・現状復旧、その他の準備 | 敷地測量、仮設用借地料 |
| 仮設建物費 | 監理事務所（敷地内）・現場事務所（敷地内）・倉庫・下小屋・作業員施設 | 宿舎、敷地外の事務所。**ユニットハウス・仮設トイレ（標準）は率に含む**（徳島の設計書 T も「仮設トイレは共通仮設費率に含まれている」、快適トイレは差額を積み上げ） |
| 工事施設費 | 場内通信設備 | **仮囲い・工事用道路・歩道構台**（＝ashiba の 仮囲い・場内通路・乗入れ構台） |
| 環境安全費 | 安全標識・消火設備・安全用品（フルハーネス含む）・隣接物の養生と補償復旧・一般的な災害防止 | **交通誘導・安全管理等の要員** |
| 動力用水光熱費 | 工事用電気・給排水設備と料金 | — |
| 屋外整理清掃費 | 屋外・敷地周辺の跡片付けと発生材処分 | 工事場所以外の屋外整理清掃、除雪 |
| 機械器具費 | 測量機器・雑機械器具 | **揚重機械器具**（＝ashiba の 移動式クレーン・タワークレーン・昇降機） |
| 情報システム費 | （表-5 に記載なし） | 情報共有・遠隔臨場・BIM 等 |
| その他 | 標準仕様書の試験費など軽微なもの | — |

- 率に含まれない: 現場環境改善費、工事場所以外の屋外整理清掃費、新たな施策の試行の費用（C 2(3)）。
- **直接仮設**（各工事種目ごとの仮設）は 遣方・墨出し・養生・整理清掃後片付け・**足場**・**災害防止（シート・ネット・朝顔）**・仮設材運搬（K 第2編 第1章 第1節 1(2)・2(1)ロ）。**共通仮設で率に含まないもの**は 仮囲い・仮設鉄板敷 など（同 2(1)イ）。
- 東京都の墜落制止用器具費（TJ）は「直接仮設工事」の行として載っている（国の C では環境安全費＝共通仮設の率に含む）。発注者で扱いが違う。

ashiba への当てはめ:
```
仮設の金額 ＝ 直接仮設（足場・シート・朝顔・墨出し…）の積み上げ
           ＋ 共通仮設の積み上げ分（仮囲い・ゲート・場内通路・敷鉄板・構台・クレーン・交通誘導）
           ＋ 共通仮設費率分 ＝ Kr × 直接工事費（建物全体の直接工事費が要る。ashiba だけでは出ないので利用者が入れる）
```

## 8. ashiba の単価表にするときの決め（提案）

1. **労務単価（§1）と共通費の式（§5）** は国の値なので既定値に入れる。地域は都道府県を選べる形にし、まず東京。
2. **くさび緊結式足場** は東京都の材工共（§2-1）を既定にし、月数は工程表の存置日数から「何ヶ月未満」を選ぶ。12m 以上は【目安】として福島・東京の +210 円／月の傾きで延ばし、帳票に【目安】と出す。
3. **枠組足場・シート・敷鉄板・仮囲いの賃料** は、配布物に他県の値を同梱しない（§0-1 の利用条件）。単価表の欄を空けて利用者が自社の値・物価資料の値を入れ、未入力なら「単価が無い」と帳票に出す。社内試験には §2-3・§6 の【目安】を使う。
4. **共通仮設費率分** は ashiba の数量からは出ない（直接工事費が要る）ので、利用者が直接工事費と工期を入れたときだけ Kr を計算して添える。率に含むもの（ユニットハウス・標準トイレ）を積み上げに入れて二重に数えないよう、§5-3 の区分で帳票の欄を分ける。
