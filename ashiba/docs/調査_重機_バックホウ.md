# バックホウ（コマツ）寸法の追加調査 — 出典つき

> 2026-11-01 の重機の調べ（利用者の指定「重機の詳細度もっとあげて」「しっかりリサーチしてね」）。文中の scratchpad/… は調べたときの一時置き場で、リポジトリには残っていない（資料は出典の URL から取り直す）。値は src/ashiba/machine.py に入れた。

調査日 2026-11-01。単位はすべて mm。「p.」は **PDF のページ番号**（印刷の頁番号ではない）。
高さは G.L.（地面）から。`*` はグローサ高さ込み（カタログの記号どおり）。

値の種類は3つに分けて書く。
- **無印**：メーカー資料に数値で書いてある値
- **〔同形〕**：海外仕様（同じ型式の -11 や LC、米国仕様など）の資料の値。国内機と作業範囲・寸法が一致するかを確かめて使った。どの点が一致したかは注に書いた
- **〔図読み〕**：国内カタログの外形図（ベクタ図）を 600〜800dpi で画像にし、寸法線の間隔から縮尺を出して画素で測った値。**メーカーの数値ではない**。同じ図の別の寸法で確かめると誤差は概ね ±1〜2%（±10〜30 mm）だが、PC78US の 490・1925 のように図と数値が 5% ほど合わないこともあったので、【目安】扱いで使うこと
