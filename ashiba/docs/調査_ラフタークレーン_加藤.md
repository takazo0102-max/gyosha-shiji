## 3. 任意張出（左右・前後で違う張出）の扱い

### 3-1 メーカー（加藤製作所）

1. **前後別**: SL-500RfⅢ・SL-750RfⅢ の注意事項は前側・後側の張出状態の組み合わせで前方領域 α・後方領域 β を決める表を持つ（上の表。S3 p4・S4 p4、公表）。前方は「前方性能」の表、後方は最大張出の表、側方は張出状態ごとの表。
2. **左右別**: 仕様書・カタログには記述が**見つからない**。ただし加藤の公式「アウトリガ反力計算」は、ラフターの全機種で張出幅を「左側」「右側」別々に選ばせる入力欄（otr_left／otr_right）、オールテレーンの一部（KA-2200・KA-3000 系）は「左前・左後・右前・右後」の 4 脚別（otr_leftfront 等）を持つ（https://outrigger.kato-ps.com/ の画面と main.js の `array_otr4_sidesupport_mtype = [41,42,43,44]`）。→ 左右で違う張出の作業状態を加藤が扱っていることは確か。その時の定格総荷重の決め方（小さい側を使う／旋回位置で切り替える）は公開資料に書かれていない。
3. **張出幅の検出**: 全 4 機種とも安全装置に「過負荷防止装置（ACS・音声警報装置付）」と「**アウトリガ張出幅自動検出装置**」（S1〜S4 p2、公表）。ACS の画面は左右のアウトリガ状態（MAX 等）を表示（SR-250RfⅡ カタログ C05842 p4 の画面写真。表示の意味の説明は無い）。
4. MR-130RfⅡ・SR-250RfⅡ の注意事項は張出状態を一つとして扱い（前後・左右別の記述なし）、前方・後方は最大張出の表、側方はその張出の表、最縮小は H 型のみ・ジブ作業不可。

### 3-2 法令

- **クレーン則 第70条の5（アウトリガー等の張り出し）**（e-Gov 法令 API、347M50002000034）: 「事業者は、アウトリガーを有する移動式クレーン…を用いて作業を行うときは、当該アウトリガー…を最大限に張り出さなければならない。ただし、アウトリガー…を最大限に張り出すことができない場合であつて、当該移動式クレーンに掛ける荷重が当該移動式クレーンのアウトリガー…の張り出し幅に応じた定格荷重を下回ることが確実に見込まれるときは、この限りでない。」 → 左右・前後で違う張出の扱いは条文に無い。「張り出し幅に応じた定格荷重」はメーカーの定格総荷重表（明細書）による。
- **移動式クレーン構造規格・適用通達（平成8年2月1日 基発第47号）**: 第13条（後方安定度）・第14条（前方安定度）の解釈に**アウトリガの張出幅・左右別の定め無し**（基発47 本文を「アウトリガ」で検索して該当なし。拡幅式クローラの警告表示（第43条）で 70条の5 に触れるのみ）。構造規格の告示本文は厚労省 DB で ID が分からず読めていない。
- **厚労省の教材**（小型移動式クレーン運転の教材、https://www.mhlw.go.jp/content/11300000/001513163.pdf ）: p47「アウトリガーが中間から最小張り出しでは、前方、後方はアウトリガー最大張り出し時と同じ能力で、側方のみ張出幅に応じた定格総荷重が設定されている」、p49「アウトリガービームを**左右均等で最大に**張り出して、ロックピンを挿入して固定する。設置場所が狭く、最大張り出しができない場合に限り、中間張り出し、最小張り出しにできる」、p110 に 70条の5 の要旨。→ 公的な教材は「左右均等」を原則として書いている。

- **日本クレーン協会**: 任意張出の扱いを書いた公開資料は**見つからず**（Web 検索で当たらない。会員向け図書は未確認）。
- **タダノ**（他社。考え方の参考）: 商品知識ガイドブック 2.0 第3章（product-guide3、PDF p6＝3-3-2）「アウトリガは最大張出が大原則」「荷をつる側は最大張出、つらない側は中間張出にし、荷をつる側を最大張出幅の定格総荷重表で作業することは、過負荷防止装置(AML)を作業状態設定することによって可能」。PDF p5 注8「スマートチャート性能は、フロントアウトリガ張出幅とリヤアウトリガ張出幅の組み合わせによって、作業が行える前方・後方の範囲（角度c、d）が異なります。また側方域でのつり上げ性能は、アウトリガ張出幅に応じた標準性能」。→ 「張出の小さい側に旋回したらその幅の性能」「張った側は大きい幅の性能」を過負荷防止装置が旋回位置で切り替える、という作り（タダノ）。加藤の SL 系の前後別 α・β 表も同じ考え（前後の張出で前方・後方の領域角が変わる）。

### 3-4 ツールに入れるときの決め（提案。根拠の強さ順）

1. 側方の性能は「つる側（旋回位置の側）の張出幅の表」、ただし加藤の公開資料では左右別の扱いが明記されていないので、**左右で違うときは小さい側の表を全周に使う**のが資料に反しない安全側（70条の5 の「張り出し幅に応じた定格荷重」を下回る）。
2. 前方・後方の領域（±α／±β）は、MR-130・SR-250 は表の α、SL 系は前後の組み合わせ表の α・β で、最大張出（SL 系の前方は「前方」）の表。
3. 反力は加藤の Web 計算で機種ごとに出してもらう（左右別入力あり）。

## 7. 測り方のメモ（図上の値）

- 仕様書の全体図は縮尺 1/100。pdftoppm -r 300 -gray で起こし、画素の行・列を走査して線の位置を取った（`research5/tools_kato/scan.py`）。縮尺は図の公表寸法で確かめた（例 MR-130 ジャッキ前後 4,884 ＝ 577 画素 → 8.46mm/画素、SR-250 6,730 ＝ 795 画素）。
- 旋回中心: 平面図の前後寸法の引出線（例 MR-130 2,400 の線）と、張出幅の寸法線の中点（車体中心線）の交点。
- 運転室: 運転室の外形線を行・列で走査。外形の前外角と旋回中心の距離が図の R 寸法（R1,630／R2,380／R2,700／R2,680）と 1% 以内で合うことを確かめた。
- 高さの基準: 側面図の左の高さ寸法はタイヤ接地面から、右の寸法は機種によりジャッキ最大張出時のフロート下面（接地面の下 165／210／270／250）から測られているものがある（線の位置で確かめた）。
