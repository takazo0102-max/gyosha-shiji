## 1. 運転・操作の資格

### 1-1 バックホウ（車両系建設機械 整地・運搬・積込み用及び掘削用）

| 区分 | 条文 | 要旨 |
|---|---|---|
| 3t 以上（技能講習） | 安衛令20条12号 | 「**機体重量**が3t以上」の令別表第七 第1・2・3・6号の建設機械（自走）の運転（道路上の走行を除く）は就業制限 |
| 〃 資格の中身 | 安衛則41条・別表第三 | 令20条12号のうち別表第七 第1・2号 → 車両系建設機械（整地・運搬・積込み用及び掘削用）運転技能講習の修了者 等 |
| 3t 未満（特別教育） | 安衛則36条9号 | 「**機体重量**が3t未満」の令別表第七 第1・2・3・6号の機械（自走）の運転（道路上の走行を除く） |
| 機械の区分 | 安衛令 別表第七 | 一 整地・運搬・積込み用、二 掘削用、三 基礎工事用、四 締固め用、**五 コンクリート打設用（1 コンクリートポンプ車）**、六 解体用 |

**境目は運転質量ではなく「機体重量」**。
- 厚生労働省のテキスト（車両系建設機械運転技能講習の補助教材）1.2「車両系建設機械に関する用語」（PDF p.10）: 機体重量とは**作業装置を除いた乾燥質量**（燃料・油類・水等が入っていない機械本体の質量）。機械重量（作業装置付き・湿式）、機械総重量（機械質量＋最大積載質量＋55kg×乗車定員）とは別。
  https://www.mhlw.go.jp/content/11300000/000774492.pdf
- 車両系建設機械構造規格（昭和47年労働省告示第150号）は、機体重量と機械総重量の**表示**を求める（定義そのものはテキスト側）。
  https://www.mhlw.go.jp/web/t_doc?dataId=74053000&dataType=0&pageNo=1
- コマツのカタログは「機械質量」と「機体質量」を別の行に載せている（手元のカタログ画像で確認）:

| PC38UU-6N0 キャブ | 3,830 kg（増量 4,020） | 2,910 kg（**増量ウエイト 3,100**） | 標準は特別教育、増量ウエイト付きは技能講習 |
| PC78US-11 | 7,710 kg | 5,970 kg | 技能講習 |

### 1-2 コンクリートポンプ車
- ポンプ車は安衛令 別表第七 **第五号**（コンクリート打設用機械）。安衛則94条の2第1項2号が「車両系建設機械＝令別表第七の建設機械で動力を用い不特定の場所に自走できるもの」と定義しており、ポンプ車も車両系建設機械。
- 作業装置の操作: **安衛則36条10号の2**「令別表第七第五号に掲げる機械の作業装置の操作の業務」→ 特別教育。**machine.py の「36条10号の2」は合っている**。
- 現場内の走行（運転）: 令20条12号・安衛則36条9号はどちらも別表第七の第1・2・3・6号だけで、第5号は入っていない → 安衛法上の運転資格の定めは無い（公道は道交法の免許）。
- 公道: PY120B-26D 16.95t・PY140-36A 24.99t はどちらも車両総重量 11,000kg 以上 → 大型自動車 → 大型免許（下の 1-6）。

|---|---|---|
| 作業床 10m 以上 | 安衛令20条15号・安衛則41条別表第三 | 高所作業車運転技能講習の修了者 等（道路上の走行を除く） |
| 10m 未満 | 安衛則36条10号の5 | 特別教育（道路上の走行を除く） |

## 3. 立入禁止・接触防止

| 機種 | 条文 | 要旨 |
|---|---|---|
| バックホウ・ポンプ車 | 安衛則158条 | **運転中の車両系建設機械に接触する**おそれのある箇所への立入りを、表示等で禁止。誘導者を置いて誘導させるときは除く（範囲は前のアタッチメントも含む「機械に接触するおそれのある箇所」で、後端に限らない） |
| ポンプ車 | 安衛則171条の2第3号 | コンクリート等の吹出しで危険が生ずる箇所への立入禁止 |
| ポンプ車（業界団体） | 全国コンクリート圧送事業団体連合会「労働災害の防止」 | ブーム直下に作業員を立ち入らせない（法令ではない）。 https://www.zenatsuren.com/pages/67/ |
| 移動式クレーン | クレーン則74条 | **上部旋回体と接触する**おそれのある箇所への立入禁止 |
| 移動式クレーン | クレーン則74条の2 | ハッカー・クランプ1個・1箇所玉掛け・複数の荷の未固定・磁力/陰圧・動力下降以外のときは、つり荷の下への立入禁止 |
| ダンプ・生コン車（貨物自動車） | 安衛則151条の7 | 運転中の車両系荷役運搬機械等またはその荷に接触するおそれのある箇所への立入禁止（誘導者を置けば除く） |
| 高所作業車 | なし | 高所作業車の節（194条の8〜194条の28）に接触防止・立入禁止の条は無い（194条の19 は修理時のブーム降下防止）。物の落下は一般則の安衛則537条（防網・立入区域の設定等） |

**旋回半径に足す余裕の数値**: 公的資料に**見つからなかった**。
- 国交省「建設機械施工安全マニュアル」（平成22年）は「旋回半径内には立入らない」（PDF p.78）、「カラーコーン等を使用して旋回範囲を明示する」（p.116）、「旋回範囲内立入禁止措置」（p.172）と書くだけで、m の数値は無い。
  https://www.mlit.go.jp/sogoseisaku/kensetsusekou/kankyou/mic/safe_manual/manual_all.pdf
- 茨城労働局のリーフレット（ドラグ・ショベル）も「接触の危険がある箇所は立入禁止、できなければ誘導者」で数値なし。
- 「最大旋回半径＋1m 以上」とする記事は民間の解説サイトのみで、公的根拠は示されていない（採用しない）。
→ machine.py の `KEEP_OUT = 0.5` は**公的根拠なし**。社内・現場の決めとして扱うのが正しい。

## 4. アウトリガ・ジャッキの下の敷板・敷鉄板

### 4-1 条文
| 機種 | 条文 | 要旨 |
|---|---|---|
| 移動式クレーン | クレーン則70条の3 | 地盤が軟弱・埋設物の損壊のおそれ等で転倒のおそれがある場所では使用禁止。ただし転倒防止に**必要な広さ及び強度の鉄板等**を敷き、その上に設置したときは可 |
| 〃 | クレーン則70条の4 | その場合、アウトリガーは鉄板等の上で転倒のおそれのない位置に |
| 〃 | クレーン則70条の5 | アウトリガー・**拡幅式のクローラ**は最大限に張り出す（張り出し幅に応じた定格荷重を確実に下回るときは除く） |
| 車両系建設機械（バックホウ・ポンプ車） | 安衛則157条 | 運行経路の路肩の崩壊防止・**地盤の不同沈下の防止**・幅員の保持 等。路肩・傾斜地では誘導者。アウトリガ・敷板の個別規定は無い（173条の敷板・敷角等はくい打機・くい抜機） |
| 高所作業車 | 安衛則194条の11 | **アウトリガーを張り出すこと**、地盤の不同沈下の防止、路肩の崩壊防止 等 |

→ どの条文も**面積の数値は無い**（「必要な広さ及び強度」）。

### 4-2 面積の考え方（公的研究機関・業界団体）

（表3・表4 の鉄板厚 22mm の行は、machine.py に入れるときに日本クレーン協会のページの表を画面で見て列を数え直した: OUTRIG_TABLE・CRAWLER_TABLE）

- **日本クレーン協会**「作業現場における移動式クレーンの地盤対策について」（出典として日本建設機械化協会「移動式クレーン、杭打機等の支持地盤養生マニュアル」を明記、1kgf≒10N で換算）
  https://cranenet.or.jp/susume/susume00_09_old.html
  - 式(2): アウトリガー1脚の最大反力の目安 ≒ (機体質量＋つり荷質量)×9.8×0.7〜0.8（正確な値はメーカーに確認）
  - 式(3): クローラの平均接地圧＝(接地質量＋つり荷)×9.8／シュー全接地面積。一般に 40〜80kN/m²（つり荷を含まない）。実際はジブ方向で三角形・台形分布になり、**最大接地圧は平均より大きい**（走行時は平均の 1.2〜2 倍との文献ありとも）
  - 式(4): 最大接地圧＝最大反力／接地面積
  - 表3「トラッククレーン等のアウトリガー1脚に必要な鉄板等の目安」（脚荷重 100〜1,000kN × 土質）: 例 軟らかい粘性土（短期 100〜300）で 100kN → 1.2×1.2m（鉄板 25mm）、200〜400kN → 6.0×1.5m（**敷鉄板2枚**）、500kN 以上 →「−」（敷鉄板では対応できず他の養生方法）。0.6×0.6m は「**厚さ7cmの敷板**」で、中硬質土以上・100kN の欄などにだけ出てくる
  - 表4「クローラクレーンに必要な鉄板の枚数」（**クローラの最大接地圧** 100〜600kN/m² × 土質）: 例 軟らかい粘性土で 100 → 0枚、150 → 1枚、200〜250 → 2枚、300 以上 →「−」
- **日本建設機械施工協会**「支持地盤養生マニュアル よくある質問と回答」（2025/2/12）

  - マニュアル p.23: 移動式クレーン等の作用荷重は短期荷重 → 地盤支持力は**短期許容支持力（安全率 Fs＝1.5）**
  - p.17・p.54: ラフテレーンの最大反力は「機体重量＋吊り荷重の 80%」で計画
  - p.34・p.92・p.96: 敷鉄板は全面積でなく**有効幅の面積**で効く。有効面積比はトラッククレーン 42%・50%、クローラクレーン 44%（1枚）・66%（2枚）（根拠資料は現存せず回答不可との注記）

- **労働安全衛生総合研究所**（旧 産業安全研究所）安全資料 NIIS-SD-No.22（2006）「移動式クレーンの安定設置に必要な地盤の支持力要件」
  https://www.jniosh.johas.go.jp/publication/doc/td/SD-No22.pdf
  - p.12: 1本のアウトリガーの最大反力は機体質量＋つり荷の 70〜80%。敷板 0.18m² だと 1MPa に達する例
  - p.87〜88（8.3 災害防止対策の提案）: つり上げ荷重 **20t を超える**移動式クレーンは設置地盤の調査が必要。アウトリガーの接地圧は**極限支持力に対し安全率 3** を標準に（短期 Fs1.5 では動的な沈下で危険が増す場合があるとの解析）
- 国交省「建設機械施工安全マニュアル」: 「アウトリガには敷鉄板等を使用する」（PDF p.116）。p.178（車両積載形クレーンの手順と見られる頁）に「敷板は厚さ 25mm、一辺 50cm 以上の鉄板がよい、盤木などは不可」
- **全国コンクリート圧送事業団体連合会**（ポンプ車）: アウトリガは常に両側最大に張り出し、ジャッキは受盤木を敷いて完全に接地。乗入構台・コンクリート舗装など強固な地盤以外は**敷鉄板で養生・補強**してから設置。数値（面積・反力）は無い。
- ポンプ車・高所作業車の「反力÷支持力」で敷板面積を出す公的な数値表は**見つからなかった**（上の表3はトラッククレーン等のアウトリガー向け）。

## 6. 今の machine.py で直すべき所

1. **バックホウの資格の境目（license_for, kind 1）**: `m.mass_t`（運転質量＝カタログの機械質量）で 3t を判定しているが、法令は**機体重量**（作業装置を除いた乾燥質量。安衛令20条12号・安衛則36条9号）。**PC38UU-6（bh01）は機体質量 2,680kg なので特別教育（安衛則36条9号）**が正しく、今の「技能講習」は誤り（キャブ＋増量ウエイトの仕様 3,100kg なら技能講習）。Machine に機体質量（bh01 2.68・bh025 5.97・bh045 11.3・bh08 15.7 t）を持たせて判定する。条文表記は「安衛令20条12号・安衛則41条（別表第三）」が正確（今の「安衛則41条」だけでも誤りではない）。
2. **公道の免許（kind 4・5、kind 3）**: `m.mass_t > 11.0` は境界が逆（規則は「11,000kg **以上**」が大型）→ `>=`。最大積載量 6,500kg 以上も大型、7,500kg 未満は準中型（3.5t 以上）・普通があるのに分岐が無い。ポンプ車の「大型免許」は固定文字でなく同じ判定にする（今の2機種はどちらも大型で結果は合う）。ダンプ 4t は「中型（8t 限定中型も可）」と書けると親切。
3. **高所作業車のトラック式（aw12）**: 公道の免許が抜けている（車両総重量 4.5t〔目安〕なら準中型）。
4. **作業計画（plan_rule）**:
   - kind 4（生コン車）を「車両系荷役運搬機械等の作業計画（151条の3）」と言い切っているが、生コン車が「貨物自動車（専ら荷を運搬する構造）」に当たるかは**未確認**。「貨物自動車に当たる場合」等の但し書きにする。
   - kind 4・5 は「道路上の走行の作業を除く」（151条の3）と作業指揮者（151条の4）を添える。
   - kind 1・3 は 154条（調査及び記録）と 155条をセットに。kind 3 は 171条の2・171条の3 も。
   - kind 2 の「クレーン則66条の2」は合っている。kind 6・7 の「194条の9」も合っている（作業指揮者 194条の10 を添えてもよい）。
5. **KEEP_OUT = 0.5**: 法令・公的資料に数値の根拠が**無い**。コメントの「目安」を「社内の決め（公的根拠なし）」と明記し、利用者が変えられるようにする。
6. **立入禁止の範囲（check）**: 後端旋回半径にしか付けていない。安衛則158条はバックホウの前のアタッチメントも含む「機械に接触するおそれのある箇所」なので、作業装置の最大旋回半径（maxR）も出すべき（モジュールの説明文は「作業半径」と書いているのに実装していない）。条文も添える: バックホウ・ポンプ車 安衛則158条、クレーン クレーン則74条（上部旋回体）・74条の2（つり荷の下）、ポンプ車 171条の2第3号（吹出し）、貨物自動車 151条の7、高所作業車は専用の条が無く 537条（落下物の立入区域）。
7. **JACK_PAD（樹脂の敷板 600 角）**: 公的な表で 0.6×0.6m が出てくるのは「厚さ7cmの敷板」で、中硬質土以上かつ脚荷重 100kN 程度まで。軟質土（短期 100〜300）では 100kN でも 1.2×1.2m の鉄板。樹脂敷板の面積をそのまま効かせる根拠は見つからなかった（メーカー値で）。
8. **plates_for（敷鉄板の枚数）**: 敷鉄板の全面積（1.524×3.048=4.65m²）で効かせているが、マニュアルは**有効面積**（トラッククレーン 42〜50%、クローラ 44%・66%）。また表3 の敷鉄板は 6.0×1.5m（2枚重ね）で、5×10 尺1枚とは違う。軟質土で脚荷重 500kN 以上は敷鉄板では不可（地盤改良）なのに、今は何でも「2枚」で済ませている。表3 を引くか、有効面積の係数を掛け、足りなければ「敷鉄板では不可」と出す。
9. **クローラの接地圧判定**: カタログの**平均接地圧**（つり荷なし）を地盤の値と比べて OK にしているが、表4 は**最大接地圧**で枚数を決める。吊り作業時の最大接地圧は平均より大きい（日本クレーン協会）。今の「OK」は危険側。少なくとも「平均接地圧・つり荷なし」と注記し、メーカーの最大接地圧で確認させる。
10. **SOIL_Q = 100**: 表2 の軟質土の下限（軟らかい粘性土 100〜300、ローム軟質 100〜150）に当たり、既定値として妥当な側。ただし「調べていない地盤の既定値」であることを帳票に明記。労働安全衛生総合研究所は **20t を超える移動式クレーン（cc50・cc70・cc90）は地盤調査が必要**、接地圧は極限支持力の 1/3 を推奨しているので、クレーンでは「地盤調査の値で」の注意を出す。
11. 合っていた所: ポンプ車の操作 36条10号の2、移動式クレーン 5t 以上の免許（クレーン則68条）、玉掛け 221条、高所作業車 10m 以上 令20条15号・10m 未満 36条10号の5、クレーン 66条の2、高所作業車 194条の9。
