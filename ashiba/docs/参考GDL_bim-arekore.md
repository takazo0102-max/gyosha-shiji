# 参考GDL（bim-arekore.com 配布の足場オブジェクト）から学んだこと

2026-10-15 に ~/Downloads の3ファイルを読んで整理した。出典は https://www.bim-arekore.com/
（足場計画.gsm は CC BY-ND 4.0、足場MVO.gsm・次世代足場.gsm は CC BY 4.0）。
コードを写すのではなく、作り方と実寸法を本ツール（ashiba_line / ashiba_detail）に取り入れるための覚え書き。

## 1. 足場計画.gsm — 割付ラインを手で動かせる計画用オブジェクト

役割は本ツールの `ashiba_line` に近い（1辺＝1オブジェクト、スパン配列を持つ）。違いは **Archicad 上でホットスポットを引いて割付を直せる** こと。

### パラメータ構成
- `standard`（インチ／メートル）→ `sizeList` = 1800/1500/1200/900/600/300（インチは 1829/1524/1219/914/610/305）
- `width`（建地列間隔。`sizeList` から選ぶ）、`height`（層高）、`total_height` → `num_z = int(total_height / height)`
- `points_x` と `x[]`（支柱位置）、`span_x[]`（集計したスパン）、`insertX[]` / `insertXPrev[]`（頂点追加用）
- `st_pillar` / `ed_pillar`（端の支柱の有無。隣の辺と共有するコーナー支柱を抜く発想）
- `st_adjuster` / `ed_adjuster` + `Len`（端の調整材。付けると端支柱を強制ON）
- `jack` / `jack_h`（0.05〜0.35 に `VALUES RANGE` で制限）
- `display_mode`（mvoに依存／配置調整①／配置調整②／階段調整）、`expression`（線表示／面表示）
- `stair_num[]` / `stair_list[]` / `stair_reverse`

### 取り入れたい作り方
1. **スパンの丸め（1Dスクリプト）**: 隣接点の差 `dif` を `sizeList` の中間値で区切って最寄りの規格に丸める。`dif ≤ 最小/2` なら点を消す。
   本ツールは Python 側で割付を解くので同じロジックは要らないが、**「手で動かした後に規格へ吸着する」** 考え方はホットスポット編集を足すときに必要。
2. **頂点の追加・削除**: `GLOB_MODPAR_NAME = "insertX"` で動かされた配列要素を見つけて `points_x` を増やし、長さ0の区間は `PUT/GET` で詰める。配列を縮めるときは一時配列（`reduceX[]` 等）に写してから `PARAMETERS` で書き戻す。
3. **編集ホットスポットの3点セット**: `HOTSPOT base, id, param, 1+128` / `move, 2` / `ref, 3` を 2D・3D 両方に置く。`AC_show2DHotspotsIn3D = 0` で2Dのものを3Dに出さない。
4. **階段をホットスポットで指定**: スパン中央のホットスポットを引いた距離 `stair_list[i]` を `±L/12, ±L/4, ±3L/8` で区切って `stair_num = -3..3` に変換（符号が向き、1＝毎層、2＝1層目から1層おき、3＝2層目から1層おき）。スパンが 1800 未満なら階段は置けない（`stair_num = 0`）。
5. **3Dを線で描く `expression = 線表示`**: `LIN_` と `HOTLINE` だけで支柱・水平材・階段（斜線）を描き、面表示のときだけ `RECT` / `PLANE`。**40m級の面でも軽い**。本ツールの 3D は `resol 12` で 7.9秒/30m面だが、計画初期の「線表示」モードは有用。
6. **3Dにスパン寸法文字**: `DEFINE STYLE "txt3d"` → `TEXT 0.005, 0, str(...)` を `ROTX 90`（平面ビューなら `ROTX 0`）で置く。
7. **ジャッキ**: z=0 から `-jack_h` へ線を下ろし、脚元に 100×100 の四角を線で描く。z方向の編集ホットスポットを `MULZ -1` の中に置く。

### 本ツールとの対応
| 足場計画.gsm | ashiba_line |
|---|---|
| `x[]` / `span_x[]` | `spanList`（Python が解く） |
| `st_pillar` / `ed_pillar` | `cornerS` と `outer_corner_posts()`（コーナー支柱の扱い） |
| `st_adjuster` / `ed_adjuster` | 渡し区間（`brD`）と端数スパン |
| `jack_h` 0.05〜0.35 | `jackOut` / `jk[]`（脚ごと）＋敷板 `sh[]` |
| `stair_num` ±3 | `stairList`（区間と向き、踊り場は Python） |
| `expression` 線／面 | 無し（→取り入れ候補） |
| `display_mode` | `showDim` のみ |

## 2. 足場MVO.gsm — モデル表示オプション（ライブラリグローバル）

- `ui_dialog "足場の表示設定"` に `view_mode`（単線表示／投影表示）1つだけの MVO 部品。
- 部品側は `success = LIBRARYGLOBAL("足場MVO", "view_mode", mode)` で読む。
- 単線表示: `rect2 + 対角線 + hotline2`。投影表示: `PROJECT2 3, 270, 3`。

**取り入れ方**: 本ツールの平面は 2D スクリプト直描きなので、「単線（割付検討用）／詳細（提出図用）／注記なし」を MVO で切り替えられると、foundation-rebar で要望のあった「平面に注記は不要」と同じ要求に図面側で応えられる（`showDim` をオブジェクトごとに触らなくてよい）。

## 3. 次世代足場.gsm — 1スパン分の精密モデル（B系列・ピッチ475）

`pattern`（端部／入隅／その他）× `select_pos`（中間／最下段／最上段）で 1スパン分を組み、`A`（1829/1524/1219/914/610）× `B`（1219/914/610）× `ZZYZX`=1.9 を `VALUES` で固定。

### 実寸法（3Dの作り込みに使える。すべて mm）
| 部材 | 寸法 |
|---|---|
| 支柱 | φ48.6、ピン φ41.9 L200（連結穴 φ13）、フランジ φ106 t6（丸穴4＋角穴4）を **475 ピッチ**（z = -35 + 475×j） |
| 布材 | φ43、支柱芯から 78 で爪、爪 60×10 に楔（30×60）、楔は `ruledsegmented` |
| アンチ（踏板） | 幅 490 / 240、支柱芯から 70、板厚 50、両端に爪（`prism_` の輪郭） |
| アンチの並び | B>1200: 490×2（y=362, 1219）／900<B<1200: 490(y=580)+240(y=210)／B<900: 490(y=305) |
| ブレース | φ22、支柱芯から 100、斜材の高さ 950、**上爪の 70 上に手すり管**（`ブレース手摺` = 先行手すり一体型の表現） |
| 階段 | 8段、蹴上 1.9/8、踏面 1.829/8、ささら 60×20、踏板 200×430×20 |
| 根がらみ支柱 | フランジ下 238 の短支柱（最下段のみ） |
| ジャッキベース | ナット h32 φ42、ロッド φ36 × `jack_len`、ベース板 140×140 t5、ハンドル L178 φ20 |

### 作り方で参考になる点
1. **3Dに切断面**: `GLOB_CUTPLANES_INFO[1]`（切断高さ）と `[3]`（下限）を `cutplane` に使い、平面図の切断高さに合わせて 3D を切る。`GLOB_VIEW_TYPE = 2`（平面）以外は固定値。投影表示（`PROJECT2`）と組み合わせると、どの層の平面を出しても正しく見える。
2. **数量を部品のパラメータに書き戻す**: 1D で `pillar_num / ledger_num / endStopper_num / brace_num / anti_num / stairs_num / jackBase_num` を `PARAMETERS` に入れる → Archicad の一覧表（スケジュール）で合計できる。
   本ツールは Python で数量表を作るが、**面ごとの本数を `ashiba_line` のパラメータに持たせれば Archicad 側の一覧表でも拾える**。
3. **`hideparameter "flip"`** で、その型（入隅）以外では不要なパラメータを隠す。
4. 布材の爪・楔・フランジを `cutpolya` / `revolve` / `ruledsegmented` で作る。見た目は良いが面数が多い。本ツールの 3D（resol 12、30m面 7.9秒）とは目的が違う（1スパンの精密表現 vs 建物一周の計画）。

## 4. 取り入れ候補（優先順）
1. **3Dの線表示モード**（`expression` 相当）: 計画初期・40m級で軽い。`LIN_` で支柱・布材・床の輪郭だけ。
2. **MVO で平面の表現切替**（単線／詳細／注記なし）: `LIBRARYGLOBAL` を読む。既定は詳細。
3. **面ごとの数量を部品パラメータへ**（支柱・布材・踏板・手すり…本数）: Python の数量と同じ値を `ashiba_line` に書く → 一覧表で合計。
4. **3Dの実寸法の反映**: フランジ（φ106 t6、475/450ピッチ）、布材の爪 78、踏板の支柱芯からの逃げ 70、ブレース φ22 と上爪+70 の手すり管。コマ（フランジ）は既にあるので径・厚み・位置を合わせる。
5. **ホットスポットでスパン・階段を直す**: 部品側で動かした値を Python に戻す往復が要るので後回し（`GetGDLParametersOfElements` で読み戻せる土台はある）。
6. **3Dにスパン寸法文字**（`txt3d`）。

## 5. 使わないもの
- 1スパン単位の `pattern`（端部／入隅／その他）の分け方。本ツールは 1辺＝1オブジェクトで、コーナーは `cornerS` で処理する。
- インチ／メートルの `standard` 切替。本ツールは系列（`series_id`）で持つ。
