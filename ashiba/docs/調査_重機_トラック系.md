# トラック系重機の寸法（出典つき）— ポンプ車・生コン車・ダンプ・高所作業車・垂直昇降

> 2026-11-01 の重機の調べ（利用者の指定「重機の詳細度もっとあげて」「しっかりリサーチしてね」）。文中の scratchpad/… は調べたときの一時置き場で、リポジトリには残っていない（資料は出典の URL から取り直す）。値は src/ashiba/machine.py に入れた。

調べた日: 2026-11-01。単位は mm（ことわりの無いもの）。
値の種類を次の印で分ける。

- **公表**: 出典の表・寸法線にそのまま書いてある値
- **算出**: 出典の数値どうしの足し引き（式を書く）
- **図上**: 出典の寸法図を画素で測った値。図に書かれた寸法（全長など）で縮尺を取った。誤差の目安は ±50（ポンプ車）・±100〜200（小さい図）
- **参考**: 同じクラスの別の車など、型式が違う出典の値
- **見つからず**: 当たった資料を書く

図の切り出しは `research2/truck/img/`、ダウンロードは `research2/truck/<名前>/` に置いた。
